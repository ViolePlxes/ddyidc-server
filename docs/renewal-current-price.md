# 续费采用当前价格

创建续费、开启自动续费及付款前均由服务端读取当前同产品/配置/周期报价。客户端quoteRevision只作展示快照兼容，不作为额外用户确认门槛。无收款、无渠道交易、无远端账单且结果明确的未支付续费单可在原订单ID上校价，保留已锁优惠与元审计，不直接修改余额。

自动续费启用后纯价格变化刷新其报价记录，不要求用户重新确认或关闭开关。旧启用设置可采用当前报价；关闭设置不会被重新开启。现有授权仍绑定归属、产品配置、周期及duration，配置或归属变化不能沿用旧授权。扣费仍通过订单、余额核验和支付事务，余额不足不扣款。

已支付、存在渠道支付或采购结果未知的订单不能自动改价/重放；回调收款证据与幂等保留。用户提示不暴露内部“完整原价/证据未确认”文案，真正无法取得可核实价格或绑定异常仍停止付款并提供正常重试/客服提示。报价请求只读，验收不得真实扣费。

本次无数据库迁移，兼容原接口与报价证据表。前端表格/卡片/详情共享Kumo自动续费说明，显示当前参考价及续费时实际价格规则。
