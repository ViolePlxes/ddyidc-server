# v0.1.174 — 独立账单与统一账单入口

统一账单区分业务订单与应收单据，保留原支付网关、BalanceService、客户归属、收益和税务发票。客户按invoiceID付款；旧付款入口亦校验账单版本、金额、客户和币种。改价保留旧快照；待核对收款阻止再次付款；拼团交付复用原已付账单。统一账单页面不再显示独立历史订单区。

后端v0.1.174与前端v0.1.210配套。061/062已登记更新器兼容清单；安装时由既有受控离线迁移流程执行并核对回填断言；应付表为billing.payable_invoices，原billing.invoices税务发票不变。既有socket迁移器只向匹配的ddyidc_runtime回环身份追加最小表权限；切换前只读验证账单表访问。grant-invoice-runtime.sql保留为人工核对清单；其他运行身份拒绝自动授权，禁止扩大整库或撤销无关权限。保留并验证真实备份，不能用本地模拟数据备份代替。不得修改001—060历史校验和。

本地build/vet、普通测试及跳过审计、相关无网络MySQL/Redis专项、真实客户会话HTTP、恢复演练与浏览器零写预览通过。未进行真实付款、入账、退款或供应商开通；安装由用户在后台手动执行。
