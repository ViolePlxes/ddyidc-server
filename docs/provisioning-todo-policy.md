# 首次开通待办口径

“开通中产品数量”仅统计未删除且首次交付尚未完成的实例。状态2也表示重装、重启、开关机、迁移等维护操作，不能单独作为开通依据。

`internal/admintodo/provisioning.go`提供共享谓词，摘要与列表使用同一投影；历史视图完整移除此谓词，保留非删除实例的既有历史范围。

- 当前状态为1或2，电源状态仅允许空值、pending、creating、provisioning。
- 已有开通时间时，必须有同一订单、同一订单商品的尚未交付记录支持首次开通过程。上游注册时间可能早于首次实际交付，因此不能单独以开通时间非空排除所有新购实例。
- 历史曾运行/停机、订单商品已交付、订单已完成，均排除；即便开通时间缺失或后续状态再次变为2，也不能重新归入首次开通。
- 不按创建时间过滤，真正积压的首次开通仍显示。

仅改变待办读取口径；不修改实例生命周期编码、不更新机器状态、不触发机器操作、不改订单/账务/数据库结构/配置。无需数据迁移。未知维护状态不推断为首次开通，仍可在实例管理、操作记录及原有异常待办中核查。

隔离MySQL回归：`bash deploy/linux/tests/test_provisioning_queue.sh`。21种分类及同一实例完成后不再进入待办、计数/列表一致和历史可见性；CI执行独立MySQL测试，普通测试中的条件跳过不计通过。
