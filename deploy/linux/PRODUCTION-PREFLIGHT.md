# 生产流量放行前检查

在正式配置、迁移、权限和 HTTPS 反向代理完成后，以本机 root 执行：

```sh
python3 /opt/ddyidc/deploy/production-preflight.py --config /etc/ddyidc/config.yaml
/opt/ddyidc/deploy/verify-linux.sh
```

任一检查非零退出不得放行生产流量。脚本只读配置、非敏感配置键及数据库权限元数据，不解密支付凭据、不输出配置原值、不修改开关、账户或资金。不提供“忽略失败”参数。依赖现有部署使用的 Python3/PyYAML、MySQL 客户端和 systemd。

本地 VM 的 local-vm、HTTP、测试策略、全开辅助程序、guard=off 应被生产检查拒绝；这不是要求关闭或修改本地测试功能。生产部署不得携带这些覆盖项。检查微信使用实际生效的 `payment.wechat.base_url`，不能用另一个未被渠道读取的 notify_url 冒充有效配置。

报告通过仅表示所列静态条件满足。HTTPS URL 检查不执行 DNS/公网连通探测，也不能证明密钥有效、回调已送达、真实结算成功或灾备可放行。还须核对：

- 正式域名/TLS、公网回调及现有通道真实证据；生产必需凭据、权限与轮换记录。
- 测试账号/商品/订单的隔离清单；历史资金及审计保留。
- 静态前端、实际版本 SHA、程序目录权限、监听、日志和告警。
- `ROLLBACK.md` 的数据库兼容边界；恢复外部事实核对。

报告只含检查名称与布尔结果；解析或权限异常统一安全失败，不打印底层异常、SQL 或密钥。留存报告时同时记录运行版本、环境及验证边界。
